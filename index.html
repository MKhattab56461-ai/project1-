HTML 1 · Page structure — the tags that hold everything 1 · بنية الصفحة — الوسوم التي تحمل كل شيء

HTML is made of tags: words between < >. Most tags come in pairs — an opening tag <html> and a closing tag </html> (note the /).

HTML تتكوّن من وسوم (Tags): كلمات بين < و >. أغلب الوسوم تأتي في أزواج — وسم افتتاح <html> ووسم إغلاق </html> (لاحظ /).

Every tag explained / شرح كل وسم

Where are these tags on THIS page? / أين توجد هذه الوسوم في هذه الصفحة؟

  • <html lang="en"> — the root element that wraps everything; lang tells browsers/translators the main language.
  • <html lang="en"> — العنصر الجذر الذي يغلّف كل شيء؛ وlang يخبر المتصفح باللغة الأساسية.
  • <head> — invisible settings: title, character set, the <style> (CSS) and <script> (JS) live here.
  • <head> — إعدادات غير مرئية: العنوان، ترميز الأحرف، ويعيش هنا <style> (CSS) و <script> (الجافاسكربت).
  • <body> — everything the visitor can see. This very sentence lives in our <body>!
  • <body> — كل ما يراه الزائر. هذه الجملة نفسها تعيش داخل <body> لدينا!

Remember: indentation (spaces) is only for humans to read — browsers ignore extra spaces. Always indent children inside their parent; it keeps code readable.

تذكّر: المسافات البادئة (الإزاحة) للقراءة فقط — المتصفح يتجاهل المسافات الزائدة. حاذِ العناصر الداخلية تحت عنصرها الأب دائماً ليبقى الكود مقروءاً.

HTML 2 · Headings, paragraphs & formatting 2 · العناوين والفقرات والتنسيق

Headings go from <h1> (biggest) to <h6> (smallest). Use one <h1> per page (it matters for search engines). Paragraphs use <p>.

العناوين تبدأ من <h1> (الأكبر) حتى <h6> (الأصغر). استخدم وسم h1 واحداً في الصفحة (مهم لمحركات البحث). الفقرات تكتب بـ <p>.

جديد هنا: <strong> مهم (يظهر عريضاً)، <em> للتوكيد (مائل)، <br> سطر جديد، <hr> خط أفقي، و <!-- تعليق --> ملاحظة لا تظهر على الشاشة.

HTML 3 · Links, images & lists 3 · الروابط والصور والقوائم

A link is an anchor: <a href="https://…">text</a>. The extra href="…" is called an attribute — information written inside the opening tag.

الرابط هو "مرساة": <a href="https://…">نص</a>. الكلمة الإضافية href="…" تُسمّى خاصية أو سمة (Attribute) — معلومات تُكتب داخل وسم الافتتاح.

Example — anchors, images, lists / مثال — الروابط والصور والقوائم

Attribute cheat-sheet / ورقة خصائص سريعة

  • <img src="pic.jpg" alt="photo"> — src = file/URL, alt = text if image can't load (also read aloud for blind users).
  • <img src="pic.jpg" alt="صورة"> — src = مسار الملف، وalt = نص يظهر لو تعذّر تحميل الصورة (ويُقرأ للمكفوفين).
  • <a href="…" target="_blank"> — target="_blank" opens the link in a new tab.
  • <a href="…" target="_blank"> — target="_blank" يفتح الرابط في تبويب جديد.
  • <ul> = bulleted list, <ol> = numbered list; each item is <li>.
  • <ul> قائمة نقطية، و<ol> قائمة مرقّمة؛ كل عنصر <li>.

HTML 4 · Forms — getting input from the user 4 · النماذج — جمع بيانات المستخدم

A <form> collects user input. Inside it you use <input> (text, email, password, number…), <textarea> (multi-line), <select> (dropdown) and <button>. Give each field a label for accessibility.

يجمع <form> بيانات المستخدم. داخله نستخدم <input> (نص، بريد، كلمة مرور، رقم…)، و<textarea> (عدة أسطر)، و<select> (قائمة منسدلة) و <button>. أعطِ كل حقل وسماً توضيحياً label لسهولة الوصول.

Example — a small form / مثال — نموذج صغير

Forms need JavaScript or a server to be useful — by itself HTML only sends data to the action address. In lesson JavaScript 3 we read an input field live without sending anything.

النموذج وحده لا يكفي — بدون جافاسكربت أو خادم، يرسل HTML البيانات فقط إلى عنوان action. في درس "الجافاسكربت 3" سنقرأ حقل الإدخال مباشرة دون إرسال أي شيء.

Color formats / صيغ الألوان

  • named — red, green… easy to remember.
  • أسماء — red أحمر، green أخضر… سهلة التذكّر.
  • HEX — #04aa6d: two digits each for Red–Green–Blue (0–9, A–F). The green used on this page is #04aa6d.
  • HEX — #04aa6d: رقمين لكل لون من الأحمر–الأخضر–الأزرق (0–9, A–F). الأخضر المستخدم في هذه الصفحة هو #04aa6d.
  • rgb(r,g,b) — numbers 0–255 per channel. Try rgb(255, 0, 0) = pure red!
  • rgb(r,g,b) — أرقام من 0 إلى 255 لكل قناة. جرّب rgb(255, 0, 0) = أحمر نقي!

CSS 3 · The Box Model — every element is a box 3 · نموذج الصندوق — كل عنصر هو صندوق

Every HTML element is a rectangle built from 4 layers, from inside out:

كل عنصر في HTML هو مستطيل مبني من 4 طبقات، من الداخل إلى الخارج:

  • 1. content — the text or image.
  • 1. المحتوى Content — النص أو الصورة.
  • 2. padding — space between content and border (inside the box).
  • 2. الحشوة Padding — مسافة بين المحتوى والإطار (داخل الصندوق).
  • 3. border — the visible edge (can be 0 / invisible).
  • 3. الإطار Border — الحافة المرئية (قد يكون 0 أي غير مرئي).
  • 4. margin — space outside the box, separating it from neighbours.
  • 4. الهامش Margin — مسافة خارج الصندوق تفصله عن جيرانه.

JavaScript 1 · What is JavaScript? 1 · ما هي الجافاسكربت؟

JavaScript (JS) is the only programming language that browsers understand natively. It reacts: it listens for events (clicks, typing, loading) and changes the page as a result. It does not need to be compiled — you write it, the browser runs it immediately.

جافاسكربت (JS) هي لغة البرمجة الوحيدة التي تفهمها المتصفحات أصلاً. إنها تتفاعل: تستمع للأحداث (نقرات، كتابة، تحميل) وتغيّر الصفحة بناءً عليها. لا تحتاج إلى تجميع — تكتبها ويشغّلها المتصفح فوراً.

Where is JS on THIS page? / أين الجافاسكربت في هذه الصفحة؟

  • There is a <script>…</script> block at the bottom, just before </body>. Putting it last guarantees the HTML above is already loaded.
  • هناك كتلة <script>…</script> في الأسفل قبل </body> مباشرة، لضمان أن HTML أعلاه قد حُمّل بالفعل.
  • Everything you click here that reacts — lessons, quiz, dark mode, the demos — is JavaScript.
  • كل ما تضغط عليه هنا فيتفاعل — الدروس، الاختبار، الوضع الليلي، والتجارب — هو جافاسكربت.

JavaScript 3 · The DOM — the bridge between JS and HTML 3 · نموذج المستند DOM — الجسر بين الجافاسكربت و HTML

DOM = Document Object Model. The browser turns your HTML into a tree of objects and JavaScript uses methods to find and change them. The 3 tools you need:

DOM = نموذج كائن المستند. يحوّل المتصفح كود HTML إلى شجرة كائنات، وتستخدم الجافاسكربت دوال (Methods) لإيجادها وتغييرها. الأدوات الثلاث التي تحتاجها:

  • document.getElementById('id') — find ONE element by its id.
  • document.getElementById('id') — إيجاد عنصر واحد بواسطة id.
  • document.querySelector('.class') — find the FIRST element matching a CSS selector.
  • document.querySelector('.class') — إيجاد أول عنصر يطابق محدد CSS.
  • element.innerHTML = '…' and element.textContent = '…' — change its content.
  • element.innerHTML = '…' و element.textContent = '…' — تغيير محتواه.

So, how does it actually work? / إذن كيف يعمل فعلياً؟

  • Every example panel has a hidden attribute data-code="some-id" pointing to an HTML string stored in JavaScript.
  • كل لوحة مثال لها خاصية مخفية data-code="some-id" تشير إلى نص HTML مخزَّن في الجافاسكربت.
  • The <pre> element is filled by JavaScript and colored by a tiny highlighter that walks through the code, tags it, and wraps keywords in colored <span>s.
  • يملأ الجافاسكربت وسم <pre> ويُلَوّنه عبر مُلوِّن صغير يمر على الكود ويغلّف الكلمات المفتاحية بوسوم <span> ملوّنة.
  • To run it, JavaScript creates an <iframe> (an independent mini-page) and writes the code into it with iframe.contentDocument.write(code).
  • لالتشغيل، تنشئ الجافاسكربت <iframe> (صفحة مصغّرة مستقلة) وتكتب الكود داخلها بـ iframe.contentDocument.write(code).
  • Reset just copies the original string again. Dirty red dot appears once you modify the code. No server involved — everything happens in your browser.
  • إعادة تنسخ النص الأصلي فقط. النقطة الحمراء تظهر عندما تعدّل الكود. لا يوجد خادم — كل شيء يحدث في متصفحك.
